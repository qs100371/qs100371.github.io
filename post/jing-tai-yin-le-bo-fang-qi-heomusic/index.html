静态音乐播放器HeoMusic

目录
  1. 1. 部署
  2. 2. 自定义配置

HeoMusic是一个基于Aplayer和MetingJS的静态音乐播放器。

项目地址：zhheo/HeoMusic

HeoMusic - 用音乐感染人心

部署

git clone https://github.com/zhheo/HeoMusic

放在网站直接就可以用。
缺省音乐是网易云歌单。地址是https://music.163.com/#/playlist?id=8152976493

自定义配置

  • url参数
    https://music.zhheo.com/?id=+ id +&server= + server
    例：https://qs100371.vip/music/?id=698720887&server=netease
    网易云歌单：华语百首 | 回忆伤人无声，唱不尽世间遗憾
    https://music.163.com/#/playlist?id=698720887

  • 修改配置文件
    把config.js.demo重命名为config.js。
    userid是播放列表id，Server是服务商，netease（网易云音乐）,tencent（腾讯）,kugou（酷狗）,xiami（小米音乐）,baidu（百度音乐）。
    还能自定义本地音乐和外链音乐，具体见项目说明页。

放在hexo网站要注意设置忽略渲染，直接发布即可。如果被hexo渲染了网页会出错。注意HeoMusic大小写，使用的时候最好都改成小写。
