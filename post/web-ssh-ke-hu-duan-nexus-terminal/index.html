Web ssh客户端Nexus Terminal

发表于2025-09-07|更新于2026-06-06
|浏览量:|评论数:

星枢终端（Nexus Terminal） 是一款现代化、功能丰富的 Web SSH / RDP / VNC 客户端，致力于提供高度可定制的远程连接体验。提供独立的本地桌面端。

项目地址：https://github.com/Heavrnl/nexus-terminal

功能特性

  • 多标签页管理 SSH 与 SFTP 连接
  • 支持 RDP/VNC 协议
  • 采用 Monaco Editor，支持在线编辑文件
  • 内置简易 Docker 容器管理面板，便于容器运维
  • 支持 IP 白名单与黑名单，异常访问自动封禁
  • 通知系统（如登录提醒、异常告警）
  • 审计日志，全面记录用户行为与系统变更

部署

docker-compose.yml：

.env：

docker compos up -d
从ip:18111访问。远程使用需设置反向代理。
