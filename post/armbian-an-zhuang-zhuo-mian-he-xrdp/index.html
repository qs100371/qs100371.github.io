armbian安装桌面和xrdp

发表于2024-11-08|更新于2026-06-06
|浏览量:|评论数:

armbian安装桌面和xrdp的过程。

安装桌面

apt install lxde
可安装桌面有lxde，xfce4，cinnamon等。

安装xrdp

apt install xrdp xorg xorgxrdp
systemctl enable xrdp

中文字体

登录的时候有时会有中文不显示，安装中文字体
apt install ttf-wqy-microhei
