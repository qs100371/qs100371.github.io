记录了安装qbittorrent的过程。

安装软件

apt install qbittorrent-nox

创建qBittorrent服务

nano /etc/systemd/system/qbittorrent.service

重新加载配置文件
systemctl daemon-reload

开启服务

systemctl enable qbittorrent

访问WebUI

访问地址：IP:8080

  • 用户名：admin
  • 密码：adminadmin
