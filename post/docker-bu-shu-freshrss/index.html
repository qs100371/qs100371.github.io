Docker 部署 FreshRSS

目录
  1. 1. cli
  2. 2. 常用 RSS 源列表

安装
以下是官方的 Docker 脚本，需要做适当修改

cli

修改数据存储路径，根据自己需求修改（可选）
-v /root/docker/freshrss/data:/var/www/FreshRSS/data \
-v /root/docker/freshrss/extensions:/var/www/FreshRSS/extensions
安装完成后可直接通过 ip:8282直接访问部署好的 FreshRSS，并完成初步设置。
