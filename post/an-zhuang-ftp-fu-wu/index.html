安装ftp服务

发表于 2024-10-14 更新于 2025-02-23

安装vsftpd：
sudo apt install vsftpd
检测是否安装：
vsftpd -version

设置upload目录的权限为775
sudo chmod 775 /srv/ftp/upload
重启服务
sudo systemctl restart vsftpd
查看服务状态
sudo systemctl status vsftpd
