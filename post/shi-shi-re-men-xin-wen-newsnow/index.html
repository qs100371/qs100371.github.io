实时热门新闻newsnow

发表于2025-03-09|更新于2025-11-05
|总字数:185|浏览量:|评论数:

newsnow本质是一个爬虫，但是整个UI画面设计得非常时尚，热点新闻来源也非常多。

项目地址：ourongxing/newsnow

特性

• 优雅的设计，优雅的阅读体验，时刻关注最新最热的新闻。
• 支持 Github 登录，支持数据同步。
• 默认 30 分钟缓存，登录用户可以强制拉取最新数据。但也会根据内容源的更新间隔设置不同的爬虫间隔时间（最快两分钟），节约资源的同时避免频繁爬取而导致 IP 封禁。
