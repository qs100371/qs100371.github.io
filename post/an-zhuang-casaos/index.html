安装casaos

2024-12-04
docker, linux

casaos是基于社区的开源软件，专注于围绕 Docker 生态系统提供简单的个人云体验。

安装

curl -fsSL https://get.casaos.io | sudo bash

体验

安装在x86设备上，应用中心的软件就都可以装了；
安装在玩客云上，由于是arm32，大半软件装不了。
