docker更换存储位置

2024-11-11

玩客云本身只有8G空间，有了docker之后不够用了。需要把docker转移到别的地方。

盒子类emmc空间较小，
在类似环境部署 Docker 时，建议：

  • 提前将 Docker 和 containerd 的数据目录都指向大容量分区
  • 监控根分区使用率，避免达到 90%
  • 定期清理日志和缓存

docker迁移

docker info | grep "Docker Root Dir"
默认在/var/lib/docker
systemctl stop docker
mv /var/lib/docker /data/docker
ln -sf /data/docker /var/lib/docker
重启docker
systemctl start docker

containerd迁移

containerd 数据目录要随 Docker 数据目录一起迁移到数据盘。
使用软链接将 /var/lib/containerd 重定向到 /data/containerd。
方法同上。
