docker更换存储位置

目录
  1. 1. 操作步骤

玩客云本身只有8G空间，有了docker之后不够用了。需要把docker转移到别的地方。

操作步骤

docker info | grep "Docker Root Dir"
默认在/var/lib/docker
systemctl stop docker
mv /var/lib/docker /data/docker
ln -sf /data/docker /var/lib/docker
重启docker
systemctl start docker
