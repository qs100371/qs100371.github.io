启用 GitHub Pages

提交代码后，进入 Actions 标签页。
选择 Deploy Douban Movies 工作流，点击 Run workflow 手动触发。

访问生成的页面

工作流运行完成后，访问：

  • 自动运行：每天更新豆瓣热映电影数据；
  • 自动部署：生成 HTML 并发布到 GitHub Pages；
  • 手动触发：可随时手动更新数据。
