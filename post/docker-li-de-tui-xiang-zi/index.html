docker里的推箱子

2025-08-17

网页版推箱子。

项目地址：ecyrbe/sokoban

用方向键操控工人推动箱子到指定位置，490个关卡越玩越上头，支持无限撤销和快捷重开，堪称浏览器里的摸鱼神器！

部署

docker-compose.yml

体验

作弊模式

按F12打开开发者工具 → Application → Local Storage → 修改SokobanLevel数值（1-489）。
