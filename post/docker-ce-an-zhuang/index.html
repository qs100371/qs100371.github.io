手动安装

如果过去安装过 docker，先删掉：
for pkg in docker.io docker-doc docker-compose podman-docker containerd runc; do sudo apt remove $pkg; done

首先安装依赖：
apt update
sudo apt install ca-certificates curl gnupg

最后安装
