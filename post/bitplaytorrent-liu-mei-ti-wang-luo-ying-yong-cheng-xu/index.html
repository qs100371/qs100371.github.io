BitPlay:Torrent流媒体网络应用程序

发表于2025-04-26|更新于2026-06-06
|浏览量:|评论数:

BitPlay 是使用 Go 构建的 Web 应用程序，可直接从浏览器中的种子流式传输视频内容。具有干净的 Web UI，支持 SOCKS5 代理，并与 Prowlarr 和 Jackett 集成以实现无缝的 torrent 搜索。

项目地址：aculix/bitplay

docker-compose.yml

mkdir /data/bitplay 用作保存设置。
docker-compose up -d

测试

  • 用自带的14分的磁力连接，很快就缓存好了可以播放。
  • 添加了一个2.6G的磁力连接，几分钟也没有开始播放。
  • 添加一个600M的电视剧磁力连接，缓冲了一会开始播放了，刚开始还有点卡，后面就正常播放。
    可能是因为晚上网络比较拥堵。
