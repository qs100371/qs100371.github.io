清除linux多余的内核

发表于2025-05-08|更新于2025-05-08
|总字数:702|阅读时长:2分钟|浏览量:|评论数:

随着linux系统的升级，磁盘空间越来越紧张，本文记录了删除多余的内核，找回可用空间的方法。

列出已安装内核

  • sudo apt list –installed | grep linux-image
    输出：
  • sudo dpkg –get-selections | grep linux-image

查看当前所用内核版本

uname -a

删除多余内核

先重启以启动最新版内核，确认没问题就可以开始清除多余的内核。

  • sudo apt remove linux-image-6.1.0-25*
  • sudo apt autoremove 统计一下，删除一个内核能减少880M空间占用(debian12)。
