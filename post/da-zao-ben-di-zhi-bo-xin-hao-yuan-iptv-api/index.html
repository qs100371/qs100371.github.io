打造本地直播信号源:IPTV-API

2025-10-27
web

影视仓的直播源不好找，就算有也会很快失效，可以自己打造一个。

项目地址：https://github.com/Guovin/iptv-api/
📺IPTV直播源自动更新平台，『✨全自动化采集、筛选、测速流程🚀』，支持丰富的个性化配置，生成结果输入播放器即可观看。

docker部署

docker-compose.yml

构建之后需要等待更新数据。

接口 描述
/ 默认接口
/m3u m3u 格式接口
/txt txt 格式接口
/ipv4 ipv4 默认接口
/ipv6 ipv6 默认接口

体验直播接口

在影视仓等直播软件中填入直播地址：http://192.168.0.4:7000/m3u 即可使用。



似乎不太高清，有时也很卡，只能是凑合着用。

现在电视直播app都不太好用，推荐：直播电视，项目地址：https://izbds.com/，适用于安卓。
