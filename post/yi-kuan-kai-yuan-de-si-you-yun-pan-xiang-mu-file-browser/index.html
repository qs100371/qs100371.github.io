一款开源的私有云盘项目:File Browser

2025-02-11

File Browser，简单实用、轻量级、跨平台，安装部署简单快捷，自带网页版文件管理器，基于 Go 语言开发，运行速度快。

项目地址：https://filebrowser.org/

部署

从IP:10000访问。
登录帐号admin，密码可由docker logs filebrowser得到，可改成能记住的字符串。




生成的分享链接：http://192.168.0.2:10000/share/3O36kkUo

2025年7月28日更新：
最新版本2.42.0在arm64上总出现权限错误。docker compose方法因为PUID，PGID总出错，不知道怎么处理。
因此固定采用v2.32.3。
