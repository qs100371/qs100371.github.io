通过GitHub工作流下载Docker镜像

2024-12-03

docker pull失败怎么办？可以试试github工作流的方法来下载。

注册/登录GitHub账户

Fork项目https://github.com/wukongdaily/DockerTarBuilder

点击Actions选项卡，进入GitHub Actions界面

运行工作流

找到名为“Run workflow”的选项，点击之后，将看到一个界面，输入需要拉取的Docker镜像名称。然后点击Run workflow按钮。
GitHub后台将自动开始拉取指定的Docker镜像。这是GitHub Actions自动化的一部分，后台会根据工作流的定义从Docker Hub或其他镜像库中拉取镜像。

查看拉取进度并下载镜像


下载文件docker-images-tar.zip，解压几次，最后文件名为-arm32.tar，用docker load方式导入。

用docker import方式会出错，提示
docker: Error response from daemon: no command specified.
See ‘docker run –help’.
这个工作流的实质是执行
docker pull --platform linux/arm/v7 ****
platform有linux/amd64,linux/arm64,linux/arm/v7等，再save image，tar，zip。
