Docker镜像的导出、导入

发表于2024-12-02|更新于2026-06-06
|浏览量:|评论数:

docker镜像的导入、导出和保存、载入命令行方法。

export和import

从容器导出到文件：
docker export 容器ID或名称 > file.tar
从文件导入镜像：
docker import - 新镜像名 < file.tar

save和load

根据镜像名或ID将镜像保存到文件，可以同时打包多个：
docker save 镜像名或ID > file.tar
docker save -o file.tar ID1 ID2 ID3
载入镜像：
docker load < file.tar

导出的文件不能混用，import导入save产生的文件，启动容器时会出错。
