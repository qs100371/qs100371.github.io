KaihongOS QEMU版试用

2026-06-06

KaihongOS桌面版3月就推出了x86版试用，但在虚拟机上不能成功安装并运行，现在终于推出了QEMU虚拟机镜像。本文记录了试用过程。

官网：https://developer.kaihong.com/freedownload

win10下试用

下载安装QEMU windows版 ，但在运行虚拟机时因不支持whpx，未能成功启动。
经查询，whpx是 Windows Hypervisor Platform（Windows 虚拟机监控程序平台）的缩写。是微软在 Windows 系统中提供的一个底层平台，允许第三方的虚拟机或模拟器（如 QEMU、Android 模拟器等）使用 Hyper-V 的硬件加速能力来运行。开启 WHPX 才能调用硬件加速，让模拟器运行得更流畅。
开启方法：
打开“控制面板” > “程序” >“程序和功能”，“启用或关闭 Windows 功能”，
在弹出的列表中找到并勾选以下两项：

  1. Windows Hypervisor Platform（Windows 虚拟机监控程序平台）
  2. 虚拟机平台
    点击“确定”，系统会自动安装所需文件，完成后重启电脑即可生效。

修改launch_qemu.bat，

执行launch_qemu.bat打开虚拟机。
