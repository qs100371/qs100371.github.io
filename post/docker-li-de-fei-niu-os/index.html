docker里的飞牛os

发表于2025-02-16|更新于2026-06-06
|浏览量:|评论数:

docker下运行飞牛os，这个容器不调用kvm，只支持x86，所以是个x86机器都可以运行。

cli部署

docker run --name=fnos --privileged -p 8088:8000 -d -t makedie/fnos:0.8.20_test

不能使用latest。这个飞牛只能看看，不能管理存储。

从ip:8088访问。
