网盘搜索PanHub

2025-09-16
web

PanHub用一个搜索框，搜遍阿里云盘、夸克、百度网盘、115、迅雷等热门网盘资源。即搜即得、聚合去重、免费开源、零广告、轻量部署。

项目地址：https://github.com/wu529778790/panhub.shenzjd.com

部署

可以一键部署到 Vercel，设置好域名就能正常使用。

Docker 部署：
docker run --name panhub -p 3000:3000 -d docker.io/wu529778790/panhub.shenzjd.com:latest
或
docker run --name panhub -p 3000:3000 -d ghcr.io/wu529778790/panhub.shenzjd.com:latest

使用





说实在的，网盘上的资源如果没有会员，直接观看效果不佳。
