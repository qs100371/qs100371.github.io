拉取镜像

docker pull photoprism/photoprism:220302-armv7
这已经是官方最旧的版本了。

浏览器打开ip:2342


能打开，但是不能使用。官方要求是至少2核3G内存以上，玩客云才1G内存，一刷新图片库就退出容器。
