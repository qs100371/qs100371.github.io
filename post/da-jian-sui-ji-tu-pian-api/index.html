之前一直用网上找的随机图片api以实现网站的随机背景图，这里自己搭建一个api。

api实现需要php环境，玩客云本机上没有，但docker里有，这里直接借用easyimage的php环境。
docker exec -it easyimage bash
进入容器。
查找php文件所在路径，
find / -name "*.php"
发现文件位于/app/web，这里就是https://img.qs100371.top的根目录了。
