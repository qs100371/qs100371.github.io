LitePan的部署和跨盘秒传

发表于2026-07-14|更新于2026-07-24
|浏览量:|评论数:

LitePan是一个轻量级多网盘挂载系统，支持主流网盘接入、WebDAV挂载、Strm生成。本文记录了部署过程和跨盘秒传功能。

官网地址：https://www.litepan.top/
项目地址：Ponphil/LitePan

LitePan 采用本地化数据存储，不依赖第三方云端数据库。推荐使用 Docker 部署，方便迁移、备份和后续升级。

Docker Compose 部署

在当前目录下执行：
docker compose up -d
启动成功后，通过浏览器访问IP:5211进入 LitePan 管理后台，通过admin/admin进入管理后台。

第一次进入需更改密码。

添加存储

  • 添加移动云盘

    Authorization令牌获取：
    打开https://yun.189.com ，登录，打开开发者工具（F12 或右键点击 -> 检查），切换到应用（Application）标签页，点击存储（Storage）-Cookie-https://yun.139.com ，
    找到 authorization 项，复制。

  • 光鸭云盘

    点击 “自动获取Token”，在弹出的认证页面中输入手机号并发送验证码。收到短信验证码后，在认证页面中填写验证码并提交。认证成功后，访问令牌和刷新令牌会自动回填到 LitePan 表单。

  • 夸克云盘
    添加账号时可优先使用 “自动获取Cookie” 功能，扫码完成后 Cookie 会自动回填到表单。
    手动获取 Cookie：
    登录夸克网盘网页版 pan.quark.cn ，
    按 F12 打开开发者工具，
    在 Network 网络选项卡中找到任意一个请求，
    复制请求头中的 Cookie 值。

  • 百度网盘

    点击 “自动获取Token”，系统会跳转到百度授权页面。由于浏览器已登录，直接选择帐号就可以认证。

跨盘秒传

alist就可以管理网盘并转成webdav供nas挂载，但不支持跨盘秒传（至少是不好用）。

LitePan支持几种网盘的跨盘秒传，为此特地注册了光鸭云盘，就为了从百度网盘到光鸭云盘的秒传。
进入管理后台，点击跨盘秒传，选择对应的网盘，指定目录，点开始传输，如果网盘上已有相应文件，就会完成秒传。

webdav

挂载网盘后可在首页进行文件浏览。


webdav挂载地址：http://ip:5211/dav 。

由于不支持移动云盘，所以注册了光鸭云盘。可惜没有从夸克云盘到移动云盘的秒传。7月24日更新：光鸭云盘新用户注册送了十天会员，怪不得下载文件特别快，到期了就只有200k。夸克用篡改猴脚本下载，一直有2M左右的速度。之后用移动云盘客户端上传，经常是秒传。
