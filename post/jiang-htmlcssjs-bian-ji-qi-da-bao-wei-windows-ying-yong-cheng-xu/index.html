为什么 Electron 应用体积大？

  • Chromium 内核
    Electron 捆绑了完整的 Chromium 浏览器内核（约120-150MB），这是支持网页渲染的核心。
  • Node.js 运行时
    包含完整的 Node.js 环境（约40-60MB），用于后端逻辑执行。
  • V8 引擎
    JavaScript 引擎的二进制文件（约20-30MB）。
  • 应用代码和依赖
    代码、node_modules 以及 Electron 自身依赖（约30-50MB）。
  • 默认包含所有平台支持
    即使只打包 Windows 版本，默认配置可能包含跨平台冗余文件。
