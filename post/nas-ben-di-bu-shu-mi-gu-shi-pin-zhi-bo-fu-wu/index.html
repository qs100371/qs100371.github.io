NAS 本地部署咪咕视频直播服务

发表于2025-11-24|更新于2026-06-06
|浏览量:|评论数:

iptv-api本地部署后源里有很多咪咕视频的信号，正好手机套餐里免费赠送了咪咕视频月卡，migu-video是一个能本地部署的migu服务。本文记录了docker部署方式。

项目地址：develop202/migu_video
核心功能：

  • 一键部署：一条命令或 Docker 直接运行
  • 直播稳定：直接从咪咕视频官方接口抓取数据
  • 跨平台兼容：可在任何支持 Docker 或 Node.js 设备运行
  • 配置灵活：支持通过环境变量快速调整配置
  • 使用简单：部署好后可以直接使用
  • 开源免费：项目开源，仅供学习交流使用

获取咪咕视频会员信息

浏览器打开咪咕视频官网：https://www.miguvideo.com，登录，按F12，切换到应用标签，找到Cookie中 www.miguvideo.com 这个网址对应的UserInfo，
例如获取到的咪咕视频会员的 UserInfo 是 55884301|nlps995522FF783E75CA33FE，其中 muserId = 55884301，mtoken = nlps995522FF783E75CA33FE。
大约25天token会过期，需要重新登录刷新token。

docker-compose.yml

docker compose up -d
直播源地址为 http://192.168.0.4:1234 ，
可在影视仓中使用。
如果没有会员，第一步可省略，去掉yml中标注会员版的内容（此行行首加#），此时只有标清画质。
咪咕普通版，画质最高支持 720P；咪咕会员版，画质最高支持 1080P。

效果演示


很清晰。

yml中mhost换成反代的公网地址，在外网也可以使用。

iptv源使用方法

各平台使用方法详细见https://github.com/iptv-org/awesome-iptv
windows上可用potplayer，VLC，linux上可用FreetuxTV，Hypnotix，VLC，android手机上可用影视仓，VLC。
手机浏览器上使用IPTV在线播放器。
https://github.com/skysolf/iptv/打包了一些软件可直接下载使用。
