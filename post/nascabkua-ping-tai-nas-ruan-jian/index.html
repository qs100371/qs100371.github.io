nascab:跨平台NAS软件

2025-07-22
nas

NasCab可远程管理照片，影音和文件，是跨平台支持Windows/Mac/Linux/Docker的nas软件。

官网：https://www.nascab.cn/
NasCab现在可以通过Docker部署，仅支持X86-64和arm64架构的Cpu。
windows，macos，android有相应的服务端和客户端软件。

部署

docker-compose.yml：

docker cli：
docker run -v /data/files:/myData -v /data/nascab:/root/.local/share/nascab -p 8888:80 -p 5555:90 -d --log-opt max-size=10m --log-opt max-file=3 ypptec/nascab
需要管理的文件在/data/files。

体验

有点象nas，但影视刮削不好，没有内容简介和演员相关，只有音视频码率。




jellyfin管理视频很好，只是刮削需要架梯子。
nascab看来只有个架子，内容做得不到位。在电信盒子上运行居然还崩了。
