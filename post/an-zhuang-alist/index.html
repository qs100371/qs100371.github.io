安装alist

2025-04-14

AList 提供了网页版界面集中管理各大网盘的文件，支持文件上传下载、文件管理、预览图片、查看文档、在线播放音乐、视频等等。AList 网页版可以支持 PC 以及手机浏览器。

项目地址：AlistGo/alist
网站：https://alist.nn.ci/zh/

AList 支持后端挂载的存储服务，白嫖上百 TB 的网络资源！支持 WebDAV，直接在线播放，收集网络资源时，也只需保存到网盘里就行，不必真正下载到本地，省时省力。

部署

  • docker cli
    docker run -d --restart=unless-stopped -v /etc/alist:/opt/alist/data -p 5244:5244 -e PUID=0 -e PGID=0 -e UMASK=022 --name="alist" xhofe/alist:latest
  • docker-compose 从ip:5244访问。

挂载存储

从首页下方“管理”进入，左侧菜单“存储”，点添加


按要求填写，主要是各网盘需要token或cookie，可按文档中的提示进行操作。

添加了百度、迅雷、阿里云和夸克，确实能很方便的访问数据，在线观看一些视频还可以，能看。至于速度，由于都没有会员，只是说能用。百度是第一个挂上去了就又删掉的，速度太慢了。

2026年5月26日更新：现在可以添加中国移动云盘，下载不限速，可再挂载本地存储， 直接从移动云盘往本地存储复制文件。

需要填入Authorization：
打开https://yun.139.com，登入，按F12，网络，getUser，
