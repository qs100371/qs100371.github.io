tmux解决退出ssh导致qemu退出的问题

2025-01-08

tmux是一个终端复用器，可以解决退出ssh导致运行中的qemu退出的问题。

安装

pkg install tmux

运行tmux

会打开一个终端一样的窗口，在里面运行启动qemu的脚本，按ctrl+b，d退出，qemu会在后台继续运行，而不会直接退出。

查看tmux所有会话

tmux ls

重新接入会话

tmux attach -t 0
