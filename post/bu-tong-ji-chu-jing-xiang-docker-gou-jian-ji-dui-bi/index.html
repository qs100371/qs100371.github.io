镜像体积对比

镜像 基础体积 安装 Nginx+PHP 后体积 特点
alpine ~5MB ~50MB 最小，适合极致轻量化
debian (slim) ~50MB ~100MB 平衡体积与兼容性
ubuntu ~70MB ~150MB 最大，但工具链最完整

结论

  • 追求最小体积 → alpine
  • 平衡选择 → debian slim
  • 需要完整工具链 → ubuntu
